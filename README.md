## What is it?
Ever wanted to load a manga in a separate reader, or send your friend the manga file from Siren? How about sending it to one of your other devices? This tool can extract all the .pns images from Firefox (and Siren) and convert them to .cbz (zipped) files with which you can do whatever you want; no need to worry about the tool breaking or the site going down

## How it works
When you download manga chapters with Siren, the data and the .webp files get encrypted and stored inside of Firefox files as binary data.

This tool decrypts them, converts all the .webp files (the manga) to .png and puts them in a foledr of your choice; it can also spit out a .cbz file.

## How to run
The tool works completely offline, but the manga needs to have been downloaded beforehand for it to work tho.

Download and run the .exe and follow the instructions in the console. READ!
The process will take some time, especially if you download a whole manga at once - the memory needed is also quite big suprisingly; Chainsaw Man is 5.5GB for example...

The tool should work in all Firefox based browsers but im not motivated enough to test it outside of Firefox itself.
